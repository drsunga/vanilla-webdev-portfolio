About - Dom Sunga

Seamless interaction is key

I started in research, where I learned to work carefully with data, test assumptions, and communicate findings clearly. Now I bring that same rigor to building software — combining a full-stack skill set with an eye for interface and motion design. I care about the details that make an interface feel intentional: clean code, thoughtful motion, and a strong typographic voice. Whether I'm shaping an API or polishing a transition, the goal is the same — build things that work well and feel right.
